# Resumen de buenas practicas

## Do's
- Utilizar un lenguaje claro y procesable
- Proporcionar herramientas y marcos de trabajo especificos
- Definir puertas de calidad y requisitos de prueba
- Incluir procesos de flujo de trabajo
- Especificar convenciones de nomenclatura
- Hacer referencia a los principios de diseno establecidos

## No hacer
- Incluir detalles especificos de la tarea que solo se aplican a veces
- Escribir volcados de documentacion de 1000 paginas
- Utilizar instrucciones vagas como "escriba un buen codigo"
- Olvidarse de especificar los flujos de trabajo de control de versiones
- Micromaneja los detalles de implementacion
- Incluir informacion temporal o cambiante

Estas son las buenas practicas a la hora de crear un `claude.md` o `agent.md`.
