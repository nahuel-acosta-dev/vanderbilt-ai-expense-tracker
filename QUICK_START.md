# Quick Start Guide

## ⚡ 5-Minute Setup

### 1. Install & Run (2 minutes)

```bash
cd expense-tracker-ai
npm install
npm run dev
```

Open **http://localhost:3000** in your browser

### 2. Add Your First Expense (1 minute)

1. Fill in today's date
2. Enter amount (e.g., $15.50)
3. Pick a category (e.g., Food)
4. Add description (e.g., "Coffee and breakfast")
5. Click "Add Expense"

### 3. Explore the Features (2 minutes)

- ✅ View your expense in the list below
- ✅ Click the expense to see edit/delete buttons
- ✅ Check the summary cards at the top for totals
- ✅ Look at the charts to visualize your spending
- ✅ Use filters to search expenses

## 🎯 Common Tasks

### Add Multiple Expenses

Repeat step 2 for each expense. The form resets after each entry.

### Find an Expense

1. Use the search box to find by description
2. Or filter by category or date range
3. Click "Reset Filters" to see everything again

### Edit an Expense

1. Click on the expense in the list
2. Click the "Edit" button
3. Modify the form above
4. Click "Add Expense" to save
5. Click "Cancel Edit" to discard changes

### Delete an Expense

1. Click on the expense
2. Click "Delete"
3. Confirm when prompted

### Download Your Data

Click the "📥 Export to CSV" button to download all (filtered) expenses as a spreadsheet file.

## ❓ FAQ

**Q: Where is my data stored?**
A: All data is stored locally in your browser (localStorage). No data leaves your device.

**Q: Can I access my data on another device?**
A: No, data is device-specific. You can export to CSV and import elsewhere manually.

**Q: What happens if I clear my browser cache?**
A: All expenses will be deleted. Export to CSV regularly for backups.

**Q: Does this app work offline?**
A: Yes! The app works completely offline once loaded.

**Q: Can I use this on mobile?**
A: Yes! The interface is fully responsive and works on phones and tablets.

**Q: How much data can I store?**
A: Most browsers allow 5-10MB of localStorage, which is plenty for thousands of expenses.
